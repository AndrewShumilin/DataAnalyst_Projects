Репозиторий содержит 7 проектов на Python по предобработке, исследовательскому анализу данных, статистической проверке гипотез и проведению A/B-тесту.

`AB_test_entertainment_app` - проект посвящён проведению A/B-теста для развлекательного приложения. Цель (опционально контекст) - Команда разработчиков рекомендательных систем создала новый алгоритм рекомендаций, который, по их мнению, будет показывать более интересный контент для каждого пользователя. Нас, как аналитика, просят помочь рассчитать параметры A/B-теста, который позволит проверить эту гипотезу, и проанализировать его результаты.

`Data_Preprocessing_for_Games_Article` - проект посвящён предобработке данных для статьи об играх. Цель (опционально контекст) - Привести данные к пригодному для дальнейшего анализа виду, произведя предобработку для разработчиков популярной игры, которые хотят написать игровую статью для привлечения новой аудитории.

`Hypotheses_and_AB_test_results` - проект посвящён проверке гипотезы, составлению аналитической записки и анализу результатов A/B-тестирования. Цель (опционально контекст) - Целью проекта является доказательство гипотезы, сформулированной коллегами и проведение анализа результатов A/B-тестирования.

`IAD_the_food_service_market` - проект полностью посвящён исследовательскому анализу данных и визуализации на Python. Цель (опционально контекст) - Основная цель проекта состоит в получении обоснованных выводов и рекомендаций для инвесторов из крупного фонда на основе исследовательского анализа данных о рынке общественного питания Москвы. Заказчик хочет открыть заведение такого типа и местоположения, чтобы максимизировать прибыль.

`IAD_the_startup_market` - проект также включает в себя исследовательский анализ данных и визуализацию на Python. Цель (опционально контекст) - Финансовая компания, занимающаяся венчурными инвестициями обратилась к нам за помощью. Заказчик хочет выбрать наиболее удачный бизнес для вложения средств. В датасете - множество стартапов и проектов, инновационных компаний. Наша задача - проанализировать данные и сделать обоснованный вывод с рекомендациями: куда лучше инвестировать для получения максимального профита.

`IAD_ticket_booking_service` - это масштабный ИАД для сервиса по бронированию билетов, а также проверка гипотез на Python. Цель (опционально контекст) - Провести исследовательский анализ данных для выявления инсайтов об изменении пользовательских предпочтений и популярности событий осенью 2024 года, а также проверить гипотезы о разнице в поведении пользователей с мобильных и стационарных устройств.

`Testing_hypotheses_for_a_scooter_rental_business` - проект посвящён проверке гипотез в бизнесе проката самокатов.  Цель (опционально контекст) - Провести статистический анализ данных и определить, оправдывает ли себя возможная выгода от введения платной подписки на самокаты.

Каждый проект содержит в себе отдельный README файл с описанием сути проекта, а также файл .ipynb - тетрадь с кодом и основным содержанием.
