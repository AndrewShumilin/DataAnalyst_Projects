# Анализ конференций TED
# О проекте
 Компания, приобретшая лицензию на проведение конференций TED, обратилась в аналитическое агентство для разработки дашборда, который поможет организовать первое мероприятие в духе классических конференций TED. Заказчику важно учитывать опыт уже проведённых конференций, чтобы сделать мероприятие запоминающимся и интересным.

**Цель проекта** — разработать дашборд, который ответит на ключевые вопросы заказчика и поможет в подготовке конференции.

**Задачи**:

- изучить датасет на верхнем уровне;

- проанализировать конференции в разрезе стран и мероприятий;

 -исследовать выступления и теги;

 -изучить информацию о выступающих;

- предусмотреть возможность детализации до отдельного выступления;

- добавить удобные селекторы для фильтрации данных.


**Структура дашборда**
1. Обзорный уровень

- Показатели, позволяющие оценить объём данных:

- количество конференций;

- количество выступлений;

- уникальное количество выступающих;

- количество тем (тегов).

2. Конференции

- Детализация от страны к конференциям со следующими метриками:

- средняя длительность выступления;

- максимальное количество просмотров выступления;

- суммарное число аплодисментов за конференцию;

- количество выступающих.

3. Выступления
- топ-10 самых смешных выступлений;

- топ-20 самых популярных тегов.

4. Выступающие

- род деятельности выступающих, которым аплодируют больше всего.

5. Детализация

- Возможность посмотреть подробную информацию о каждом выступлении.

6. Селекторы

- страна;

- название конференции;

- тег выступления;

- дата записи.

**Описание данных**

Таблица `events`
Содержит информацию о конференциях.

| Поле | Тип | Описание |
|------|-----|----------|
| conf_id | int4 | Идентификатор конференции. Первичный ключ. |
| event_name | text | Название конференции. |
| country | varchar(50) | Страна проведения конференции. |

Таблица `speakers`
Содержит информацию о выступающих.

| Поле | Тип | Описание |
|------|-----|----------|
| author_id | int4 | Идентификатор выступающего. Первичный ключ. |
| speaker_name | text | Имя выступающего. |
| speaker_occupation | text | Род деятельности выступающего. |
| speaker_description | text | Краткое описание выступающего. |

Таблица `talks`
Содержит информацию о выступлениях.

| Поле | Тип | Описание |
|------|-----|----------|
| talk_id | int4 | Идентификатор выступления. Первичный ключ. |
| url | text | Интернет-ресурс, где выступление находится в открытом доступе. |
| title | text | Название выступления. |
| description | text | Краткое описание выступления. |
| film_date | varchar(50) | Дата видеозаписи выступления. |
| duration | int4 | Длительность выступления. |
| views_count | int4 | Количество просмотров выступления. |
| main_tag | varchar(50) | Основной тег выступления. |
| speaker_id | int4 | Идентификатор выступающего. Внешний ключ к speakers.author_id. |
| laughter_count | float4 | Число случаев, когда в зале звучал смех. |
| applause_count | float4 | Число случаев, когда в зале звучали аплодисменты. |
| language_sp | varchar(50) | Язык, на котором велось выступление. |
| event_id | int4 | Идентификатор конференции. Внешний ключ к events.conf_id. |
